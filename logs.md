## 1. Успішний розрахунок

Дія: у калькуляторі введено `12 + 7`.

```text
{"timestamp":"2026-09-21T12:03:03.628Z","chatId":710194775,"step":"calc:input_received","summary":"Отримано ввід для калькулятора"}
{"timestamp":"2026-09-21T12:03:03.628Z","chatId":710194775,"step":"calc:result","summary":"12 + 7 = 19"}
```

Бот отримав вираз `12 + 7` і виконав обчислення. Запис `calc:result` із текстом `12 + 7 = 19` підтверджує успішний результат. Користувач побачив повідомлення «Результат: 19».

## 2. Некоректний ввід

Дія: у калькуляторі введено `abc`.

```text
{"timestamp":"2026-09-21T12:04:29.738Z","chatId":710194775,"step":"calc:input_received","summary":"Отримано ввід для калькулятора"}
{"timestamp":"2026-09-21T12:04:29.739Z","chatId":710194775,"step":"calc:validation_failed","summary":"Введи два числа та операцію між ними."}
```

Бот отримав `abc` і відхилив некоректний вираз. Це підтверджує запис `calc:validation_failed`. Користувач побачив повідомлення «Введи два числа та операцію між ними.» з прикладом правильного вводу та командою `/menu`.

## 3. Збій API

Дія: URL API тимчасово замінено на `https://test.nbu`.

```text
{"timestamp":"2026-09-21T12:10:21.573Z","chatId":710194775,"step":"nbu:request_sent","summary":"Запит курсу USD та EUR"}
{"timestamp":"2026-09-21T12:10:21.576Z","chatId":710194775,"step":"nbu:error","summary":"RequestError: getaddrinfo ENOTFOUND test.nbu"}
```

Запит завершився помилкою визначення адреси сервера, що видно з `ENOTFOUND` у записі `nbu:error`
